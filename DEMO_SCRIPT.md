# Three-minute demo

0:00 Open the app. Point at the model line. If it says the model is offline, say that answers will be labeled as retrieved evidence, not AI. If it says `qwen3:4b` is connected, say answers come from that local model and citations are checked.

0:20 Stay on the fictional sample. Open Overview and show that the banner says the files were not fetched from GitHub.

0:40 Open Ask and submit "How do I install this and run the tests?" Read the status. A model answer cites `[README.md:L…]`. An offline result says it is not a model answer and still lists `pip`, `python`, and `pytest` as documented, not executed.

1:20 Open Setup. Show Documented versus Configured, and say nothing on this screen was run.

1:40 Open Contribute, choose issue 1, and build the plan. If the model is connected, show the verification note. If it is not, read the line "Not generated by a model." Download the Markdown.

2:10 Paste a small public GitHub URL and analyze it. Show the indexed nested paths and any limit note. Ask a question that the README can answer. If GitHub rate-limits the request, show that error and return to the sample.

2:40 Open Gaps and say a missing file is claimed only when the retrieved tree supports it. A truncated tree is labeled partial.

Stop at 3:00. Do not claim a command succeeded, and do not claim the model answered if the header says it is offline.
